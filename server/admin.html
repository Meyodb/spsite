Mapping catégories JDC → site une catégorie JDC non mappée = produits ignorés

Choisis vers quelle catégorie du site doivent atterrir les produits de chaque catégorie JDC. « — ignorer — » signifie qu'aucun produit de cette catégorie JDC n'est créé sur le site. Seules les catégories site en mode « JDC » (soupes, plats, salades, sandwichs, desserts) reçoivent des produits automatiquement. Jus, milkshakes, boosters, boissons et goodies restent 100 % manuels.
